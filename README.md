# Первая лабораторная работа по Python

CLI-приложение на Python с калькулятором выражений и конвертером величин.
Интерфейс командной строки реализован с помощью Typer.

## Установка

```bash
pip install -r requirements.txt
```

## Команды

Справка CLI интерфейса
```bash
python -m toolkit --help
```

Калькулятор. Считает выражение внутри "EXPRESSION", Поддерживаются операторы +, -, *, /, //, %, скобки и унарные +, -
```bash
python -m toolkit calc "EXPRESSION"
```
Конвертор. Переводит числовое значение VALUE одной величины в другую величину.
Поддерживаемые единицы:
- длина: mm, cm, m, km;
- масса: g, kg;
- температура: c, f, k.
```bash
python -m toolkit convert VALUE --from UNIT --to UNIT
```

# Принятые решения

## Калькулятор
1. Происходит токенизация строки при помощи регулярных выражений в tokenization.py
2. Происходит валидация и вычисление унарных знаков в validation.py
3. Внутру функции shunting_yard_algorithm в calculation.py происходит преобразование выражения в постфиксную форму
4. Внутру функции expression_calculation в calculation.py происходят итоговые вычисления

## Конвертор
1. Внутри convertor.py происходит вычисление системы величин
2. Проиходит подсчет итогового значения:
- Масса и длина вычисляются по форумле: value *  COEFFICIENTS[from_unit] / COEFFICIENTS[to_unit]
- Температура сначала переводится в кельвины, затем в необходимую величину

Вычисления происходят при помощи Decimal
